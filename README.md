## What it does

`main.py` writes one original roast line to `/output/entry.txt`.
The line is a single sentence, 101 characters, about a pair of
wireless earbuds that never die together. One bud always gives up
first, so half of every phone call turns into a crackly one-sided
conversation.

## The line

> My earbuds die one at a time, so half my calls sound like a hostage negotiation over a walkie-talkie.

## How to run it

```sh
python3 main.py
```

It writes `/output/entry.txt` and nothing else. No network, no
arguments, no dependencies beyond the standard library.
